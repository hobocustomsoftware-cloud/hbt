# AI Prompt — Vertical-Slice Delivery Backlog

Act as an engineering manager, product owner, solution architect, QA lead, and DevOps lead.

Create a dependency-aware **MVP Delivery Backlog** from the approved requirements and implementation blueprint.

Organize delivery into working vertical slices that demonstrate user value. Avoid organizing the entire plan as isolated technical layers.

## For each epic and story include

- Stable ID and title
- User/business outcome
- Scope and exclusions
- Related requirements, use cases, modules, workflows, and API operations
- Dependencies
- Acceptance criteria
- Security, audit, offline, and observability considerations
- Backend, frontend, database, test, documentation, and operations tasks
- Definition of Ready
- Definition of Done
- Estimate range and uncertainty
- Risks and required spikes
- Demo evidence

Include:

1. Foundation/bootstrap slice
2. Identity and tenant foundation
3. Master-data setup
4. Scheduling and trip preparation
5. Booking-to-ticket journey
6. Boarding and trip operation
7. Settlement and reporting as approved
8. Offline capability increments
9. Production-readiness work

Identify the critical path and recommend the smallest first end-to-end walking skeleton.
