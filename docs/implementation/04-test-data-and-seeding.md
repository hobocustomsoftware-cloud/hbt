# AI Prompt — Test Data, Fixtures, and Seed Strategy

Act as a data architect, QA automation architect, privacy engineer, Django developer, and transportation-domain analyst.

Create the authoritative **Test Data, Fixture, Factory, and Seed Strategy** for HBT.

## Include

- Data categories: reference, demo, development, automated-test, performance, and migration rehearsal
- Tenant-safe fictional data policy
- Stable identifiers and deterministic generation
- Entity creation order and dependency graph
- Minimum coherent transport network dataset
- Users, roles, permissions, and branch assignments
- Routes, stops, vehicles, seat layouts, schedules, and trips
- Booking, passenger, payment, ticket, boarding, refund, settlement, and audit scenarios
- Boundary, invalid, fraud-like, concurrency, and offline-conflict scenarios
- Time-zone, currency, language, and Unicode cases
- Volume profiles for performance testing
- Reset, refresh, versioning, and migration behavior
- PII prohibition and sanitization requirements

Produce scenario catalogs and expected outcomes. Do not use real people, phone numbers, credentials, payment data, or production-derived records.
