# AI Prompt — Implementation Blueprint

Act as a principal Django architect, Flutter architect, PostgreSQL architect, DevOps engineer, security engineer, and technical lead.

Create the authoritative **HBT MVP Implementation Blueprint** after the MVP scope, requirements, invariants, access matrix, and API catalog have been approved.

## Include

1. Confirmed technology versions and compatibility policy
2. Modular-monolith boundaries and dependency direction
3. Backend project/package structure
4. Flutter application/package structure
5. Domain, application, infrastructure, and interface responsibilities
6. Database schema ownership and migration strategy
7. Transaction, concurrency, idempotency, and outbox strategy
8. Background jobs and messaging
9. Cache and object-storage usage
10. Authentication and authorization implementation approach
11. Multi-tenancy enforcement approach
12. Offline data, sync protocol, and conflict-resolution approach
13. API implementation conventions
14. Configuration, secrets, and environment strategy
15. Logging, metrics, traces, health checks, and audit
16. Testing architecture and test-data strategy
17. Local, CI, staging, and production topology
18. Dependency and supply-chain controls
19. Incremental implementation sequence
20. Technical risks, spikes, and decision gates

For each major choice include rationale, rejected alternatives, consequences, and an ADR requirement. Do not generate application source code in this document.
